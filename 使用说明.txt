======================================================

【一、各入口分别干什么（m3u8 转换见第九节，窗口版批量下载见第十节，托盘常驻见第十一节，无黑框启动见第十二节）】

  ★★ 无黑框入口（推荐）：X视频批量下载.vbs、m3u8批量转换.vbs
      双击直接打开窗口，不会同时弹出 PowerShell 控制台窗口，详见第十二节。
      链接 / 文件拖到 .vbs 或 .bat 图标上都能自动预加载，两种入口功能完全一样。

  ★ X视频批量下载.bat（窗口版 / 批量 / 断点续传，兼容入口）
      双击打开窗口，一次加入多条推文链接排队下载；点 × 收进系统托盘后台继续，
      中途停止或退出程序会保留半成品，下次打开自动从已下载字节接着下。详见第十节。
      视频保存到：C:\Users\用户名\下载\X视频

  下载X视频.bat（命令行版，保留）
      专用于 X / Twitter。复制推文链接（可多条）→ 双击；或把链接拖到图标上。
      视频保存到：C:\Users\用户名\下载\X视频

  获取X视频直链-给FDM.bat
      X 专用。解析出真实 MP4 直链并自动复制到剪贴板 → 在 FDM 点「+ 新建下载」按 Ctrl+V。
      只有这个用法需要在目标电脑另装 FDM。

  通用视频下载.bat  ★ 新增
      接受任意 http(s) 视频链接（B站、YouTube、Vimeo、公开 MP4 直链、网页内嵌视频等）。
      复制链接 → 双击；或把链接拖到图标上；也支持一次拖多个。
      视频保存到：C:\Users\用户名\下载\视频下载

  x_video_dl.ps1
      主脚本，三个 bat 都调用它。命令行可用参数见文末。

【二、通用模式和 X 模式的区别（重要）】

  X 模式会做 X 专属处理：链接只认 x.com/twitter.com 的 /status/数字；
  剥掉 /video/N、/photo/N 与 ? 后面的查询串；解析失败时改走公开解析接口兜底。

  通用模式把这些全部关掉：
      · 接受任意 http(s) 链接，剪贴板里可以是任何网址
      · 完整保留 URL 和查询串（?v=、?p=、&t= 等不会被破坏）
      · 不请求 fxtwitter / vxtwitter 兜底接口
      · 输出目录改为「下载\视频下载」
      · 格式优先取最佳组合，有 ffmpeg 时自动合并音视频分离流
  如果通用模式下传入的是 X 链接，仍会自动按 X 的规则处理，不会出问题。

【三、拷贝到别的电脑能不能直接用？】

  能。把「X视频下载-便携版」整个文件夹复制过去（U 盘 / 网盘均可），
  双击里面的 bat 就能用，不需要安装、不需要改路径、不需要管理员权限。

  硬前提与系统要求：
  1) 网络必须能访问目标站点。在中国大陆访问 X / YouTube 等需要代理。
     脚本自动识别，顺序：
        手动 -Proxy 参数 > Windows 系统代理
        > HTTPS_PROXY/HTTP_PROXY 环境变量
        > 常见本地端口(7897/7890/10809/1080/2080/33210)
     端口不常见可编辑 bat 或命令行加 -Proxy http://127.0.0.1:端口；海外直连加 -NoProxy。
  2) Windows 10（1803 及以上）或 Windows 11。要用到系统自带 curl.exe，
     PowerShell 5.1 也是系统自带。Windows 7 不支持。

【四、需要另外安装什么软件吗？】

  必需：无。bin\ 里已附带：
      yt-dlp.exe  约 17 MB   —— 核心解析器，内置 1752 个站点提取器 + generic 通用提取器
      ffmpeg.exe  约 139 MB  —— 合并音视频分离流
      （两个都是静态编译的单文件，无 DLL 依赖，可直接拷走）
  整个包约 156 MB。想省空间可删掉 bin\ffmpeg.exe（包变回 17 MB），
  脚本会自动改用「单一 MP4 / 最佳单一格式」，多数视频照样能下。
  可选：同目录放 cookies.txt，供需要登录的站点使用；也可加 -Login 读 Chrome 登录态
        （需先完全关闭 Chrome）。升级：用新版 yt-dlp.exe 覆盖 bin\ 里的同名文件。
  不需要 FDM：通用下载和 X 下载都由脚本自己完成，FDM 只是「取直链」那个用法可选。

【五、通用模式能不能解析某个站点？怎么自查】

  yt-dlp 内置 1752 个站点提取器，另有一个 generic 提取器能抓网页里的 mp4 / m3u8。
  主流平台大多开箱可用；但有防盗链、需登录、加密 HLS 或不在支持列表的站点会失败，
  此时脚本会打印「该站点未能解析」并给出提示。

  自查命令（在本文件夹打开 PowerShell）：
      .\bin\yt-dlp.exe --simulate --list-formats "视频链接"
  能列出格式列表就能下；报 Unsupported URL 说明没有对应提取器。
  需要登录的站点：导出 cookies.txt 放到本文件夹根目录，脚本会自动使用。

  请只下载自己有权保存的内容，并遵守目标网站的条款与所在地法律；
  本工具不提供绕过登录、付费墙、加密或版权保护措施的能力。

【六、隐私说明】

  仅 X 模式下、常规解析失败（如推文被标记为受限内容）时，脚本才会向
  api.fxtwitter.com / api.vxtwitter.com 查询兜底直链，且只发送公开的
  「用户名/推文ID」，不发送账号、cookie 或任何个人信息。
  通用模式完全不会请求这两个接口。不想用兜底可加 -NoMirror。

【七、命令行参数（可选）】

  -Generic     通用模式（bat 已自动带上）
  -OnlyLink    只解析直链并复制到剪贴板，不下载（配合 -Generic 可用于任意站点）
  -Login       读取 Chrome 登录态（需先完全关闭 Chrome）
  -NoMirror    禁用 X 的公开解析接口兜底
  -Proxy       手动指定代理，如 -Proxy http://127.0.0.1:7890
  -NoProxy     强制直连
  示例：
      powershell -ExecutionPolicy Bypass -File x_video_dl.ps1 -Generic "https://..."
      powershell -ExecutionPolicy Bypass -File x_video_dl.ps1 -Generic -OnlyLink "https://..."

【八、常见问题】

  · 提示「未找到 yt-dlp.exe」→ bin 文件夹没一起拷过去，或被安全软件删了。
  · 一直超时 / SSL EOF → 代理节点不稳，换节点重跑；脚本内置 5 次重试。
  · 通用模式提示「该站点未能解析」→ 用上面第五节的自查命令确认；
    需要登录就放 cookies.txt；不在 yt-dlp 支持列表的站点无法处理。
  · 下载出来没声音 → 确认 bin\ffmpeg.exe 还在，补回后重跑。
  · SmartScreen 拦截 → 未签名的本地脚本，点「更多信息 → 仍要运行」。

【九、m3u8 转 mp4（窗口版 + 批量，推荐）】

  ★ m3u8批量转换.bat（窗口模式）
      双击打开窗口，可以：
        · 把多个 .m3u8 文件或整个文件夹拖进列表（文件夹会递归收集里面所有 .m3u8）
        · 「添加文件」多选 / 「添加文件夹」递归 / 「添加网址」
        · 列表逐项显示状态（等待 / 转换中 / 成功 / 失败）、总进度条、运行日志
        · 「停止」随时中止；「强制重编码」；「统一输出到」指定目录
        · 完成后可自动打开输出文件夹
      也支持把 .m3u8 文件/文件夹直接拖到这个 bat 图标上，会自动预加载进窗口。
      输出：默认与源文件同目录同名 .mp4；勾选「统一输出到」则全部存到指定目录；
            网络 URL 默认存到 下载\视频下载。同名自动加序号，不覆盖。
      主程序 m3u8_gui.ps1，复用同一个 bin\ffmpeg.exe；桌面版和便携包里的入口都能用。

  m3u8转mp4.bat（命令行版，保留）
      把 .m3u8 文件拖到图标上（可多个），或双击后从剪贴板取路径 / URL，
      剪贴板为空时手动粘贴。
      本地文件 → 同目录同名 .mp4；网络 URL → 下载\视频下载。
      输出文件已存在时自动加序号，不会覆盖。

  转换策略（自动，无需选择）：
      ① -c copy 无损封装（最快、不损画质）
      ② 失败则重试 -c copy -bsf:a aac_adtstoasc（AAC/ADTS 兼容）
      ③ 仍失败则自动重编码 -c:v libx264 -c:a aac（最慢，兼容性最好）
      命令行加 -Recode 可跳过前两步、直接强制重编码。

  复用 bin\ffmpeg.exe；网络 m3u8 会自动套用 Windows 系统代理。
  注意：ffmpeg 只按 m3u8 里写明的地址取分片，分片与密钥必须能直接访问，
  工具不处理鉴权、动态接口或加密密钥的生成。

  补充（v1.2）：
    · 拖进来的如果是「文件夹」（迅雷等下载器常把任务存成同名 .m3u8 目录），
      工具会自动找里面的 .m3u8 文件：只有一个就直接用，多个会列出来让你选。
      所以拖整个文件夹即可，不必进去找文件。
    · 文件名含 [ ] ( ) 等字符也能正确处理（内部统一用 -LiteralPath，
      不会被 PowerShell 当成通配符）。
    · 路径里若含 & ^ ! 等 cmd 特殊字符，拖放可能出错，
      改用「复制路径 → 双击 bat 从剪贴板读取」更稳。

  补充（窗口版 v2）：
    · 拖整个文件夹会递归收集所有 .m3u8，一次排队批量转换；列表可移除选中项、清空。
    · 转换期间界面保持可操作，进度条和日志实时更新，「停止」在当前任务结束后中止。
    · 高级：命令行无界面批量（可放进计划任务 / 脚本）
        powershell -ExecutionPolicy Bypass -File m3u8_gui.ps1 -Headless "D:\某个文件夹"
        可选 -Recode 强制重编码、-OutDir "D:\输出" 统一输出目录；
        -SmokeTest 只做窗口构建自检、不弹窗，用于排查环境。

【十、X 视频批量下载（窗口版 + 断点续传，推荐）】

  ★ X视频批量下载.bat / x_video_gui.ps1
      双击打开图形窗口，不再是黑框命令行。原来的三个命令行 bat 全部保留，
      功能互不影响；窗口版和命令行版共用同一个 bin\ 里的程序。

  ── 怎么批量加链接 ──
      · 「粘贴链接」：先复制一条或多条链接（一行一条），点一下全部加入队列
      · 「添加网址…」：手动输入一条
      · 「导入 txt…」：选一个或多个 txt，每行一个链接，一次全部导入
      · 直接把链接文本、.txt 文件拖到窗口列表里；也可以拖到 bat 图标上，
        启动窗口时会自动预加载
      · 自动去重；可「移除选中」「清空列表」；支持一次拖多个
      · 每条都显示状态（等待 / 解析中 / ✓成功 / ⏸已暂停 / ✗失败）、
        已下载字节、结果；下方有总进度条和运行日志

  ── 断点续传怎么用 ──
      下载途中点「停止（可续传）」，或直接退出程序，正在下载的文件会保留
      已写入的部分。注意：点右上角 × 只是把窗口收进托盘，下载不会中断（见第十一节），
      要中止请用窗口里的「停止」。下次打开窗口，未完成任务会自动回到列表；
      点「开始批量下载」即从已下载字节处发 Range 请求继续，不用重头下。
      日志里出现「✓ 完成（续传）」就说明这次是接着下的。

      实现要点（便于排查）：
        1. 先用 yt-dlp -g 解析出真实 MP4 直链；受限推文照旧走公开解析接口兜底
        2. 输出文件名由「推文ID + 序号 + 直链文件名」确定，不需要重新解析元数据
        3. curl -L -C - 直接写目标文件，中断后文件即半成品，下次按文件大小续传
        4. 输出目录里的 .xdl_state.json 记录已完成项；删掉它可让所有文件重下，
           或勾选窗口里的「强制重新下载」（忽略完成标记）
      注意：只有「单文件 MP4 直链」支持字节级续传（X 视频绝大多数属于此类）。
      分片流 / 音视频分离流会自动改用 yt-dlp 原生下载，其 .part 文件也支持
      续传，但不能跨会话按字节恢复。

  ── 窗口选项 ──
      · 统一输出到：默认 下载\X视频，可改到任意文件夹
      · 强制重新下载（忽略已完成标记）
      · 禁用公开解析接口兜底
      · 完成后打开输出文件夹
      · 「打开输出目录」随时查看；「停止（可续传）」随时中止

  ── 高级 / 无界面批量（可放进脚本或计划任务）──
      powershell -ExecutionPolicy Bypass -File x_video_gui.ps1 -Headless "链接1" "链接2"
      可选：-OutDir "D:\输出"、-NoMirror、-Proxy http://127.0.0.1:7890、
            -NoProxy、-Login（需先关 Chrome）、-ForceRedownload
      -SmokeTest 只构建窗口不弹窗，用于自检环境。

  首版范围说明：窗口版聚焦「X 视频 + 批量 + 断点续传」。
  通用站点下载、取直链交给 FDM、m3u8 转 mp4 仍分别用原来的
  「通用视频下载.bat」「获取X视频直链-给FDM.bat」「m3u8批量转换.bat」，
  没有搬进这个窗口，避免影响主流程。

【十一、系统托盘常驻（点 × 不退出）】

  适用窗口：X视频批量下载.vbs / .bat、m3u8批量转换.vbs / .bat 打开的窗口。
  命令行下载、取直链、m3u8 转 mp4 那几个黑框工具行为不变，关掉就是结束。

  · 点窗口右上角 × → 窗口隐藏、程序不退出，图标留在系统托盘，
    正在进行的下载 / 转换继续在后台跑；任务完成时用气泡通知代替弹窗。
  · 双击托盘图标，或右键 →「显示主窗口」→ 恢复窗口看进度、加任务。
  · 真正退出：托盘图标右键 →「退出程序」，或窗口右下角「退出程序」按钮。
    任务进行中会先确认，等当前任务收尾后才关闭，不会把 curl / ffmpeg
    子进程丢成孤儿。
  · 任务栏「最小化」按钮仍是普通最小化到任务栏，不会进托盘。
  · 关机、注销、任务管理器结束进程时仍会正常退出并清理托盘图标。
  · Windows 11 常把托盘图标折叠进「^」：点「^」展开，把图标拖到常显区即可；
    看不到气泡通知时，检查「设置 → 系统 → 通知」是否开启。

  一句话：关掉的是窗口，不是任务。想停下载请用窗口里的「停止（可续传）」，
  或直接退出程序；两者都会保留半成品，下次可续传。

【十二、不再弹出 PowerShell 窗口（无黑框启动）】

  以前的窗口版用 .bat 直接拉起 powershell.exe，所以开窗口时旁边会跟着一个
  黑色控制台窗口。现在换成 Windows 自带的图形脚本宿主启动，它本身没有控制台
  窗口，也不会为 PowerShell 创建控制台窗口。

  · 推荐：双击「X视频批量下载.vbs」或「m3u8批量转换.vbs」
      → 桌面只出现程序自己的窗口，完全没有任何黑框。
      两个 .vbs 内容相同，靠文件名决定打开哪个脚本，别随便改文件名。
  · 兼容：双击原来的 .bat 也可以，它现在只把参数转交给 .vbs。
      cmd 窗口一闪即退（零点几秒），不会再有常驻的 PowerShell 黑框。
      把链接、.txt、.m3u8 文件拖到 .vbs 或 .bat 图标上都能自动预加载。
  · 四个命令行工具（下载X视频.bat、获取X视频直链-给FDM.bat、
      通用视频下载.bat、m3u8转mp4.bat）本来就靠黑框显示进度和「按任意键继续」，
      保持原样；它们不是窗口程序，隐藏了反而没法用。

  实现与便携性：
      启动器是纯文本 .vbs（系统自带，无需安装、无需编译、无需管理员权限），
      以「隐藏窗口 + 不等待」方式拉起 PowerShell；两个 .ps1 一行未改，
      托盘常驻、断点续传、批量下载逻辑全部照旧。整个文件夹拷到别的
      Win10/11 电脑照样能用。
      bat 按中文系统 ANSI(GBK) 保存，其中的中文文件名才不会被 cmd 读成乱码；
      非中文系统里若双击 bat 提示「启动失败」，直接双击 .vbs 即可。
      个别安全软件会拦截新写入的 .bat（本机出现过一次），遇到这种情况
      以 .vbs 为准，或把 .vbs 加进安全软件白名单。

  版本：v7 / 2026-11-24（无黑框启动；v6 托盘常驻；v5 窗口版批量下载 + 断点续传）
