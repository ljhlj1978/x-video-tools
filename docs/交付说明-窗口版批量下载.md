# X 视频批量下载器（窗口版 + 断点续传）交付说明

日期：2026-11-24

## 结论

把此前命令行的 X 视频下载工具做成了图形窗口版，支持一次排队多条链接、以及真正的字节级断点续传。原来的命令行工具全部保留，功能互不影响。

## 本机实际位置

- 主入口：`C:\Users\Administrator\Desktop\X视频批量下载.bat`
- 主程序：`C:\Users\Administrator\Desktop\x_video_gui.ps1`
- 完整便携包：`C:\Users\Administrator\Desktop\X视频下载-便携版\`（156 MB，含 `bin\yt-dlp.exe` 与 `bin\ffmpeg.exe`，整个文件夹可拷到别的 Win10/11 电脑直接用）
- 说明文档：便携包内 `使用说明.txt`（v5，第十节写窗口版用法）

本归档目录内附 `X视频批量下载.bat`、`x_video_gui.ps1`、`使用说明.txt` 和 `bin\yt-dlp.exe`，双击 bat 即可运行；ffmpeg 未随本目录附带（脚本会自动改选单一 MP4，不影响绝大多数 X 视频）。

## 断点续传怎么工作

1. `yt-dlp -g` 解析真实 MP4 直链；受限推文常规解析失败时，自动改走公开解析接口兜底。
2. 输出文件名由「推文 ID + 序号 + 直链文件名」确定，不依赖重新解析元数据。
3. `curl -L -C -` 直接写目标文件。中途点「停止」或关掉窗口，半成品会保留；下次打开窗口自动恢复未完成任务，从已下载字节处发 Range 请求续传。
4. 输出目录里的 `.xdl_state.json` 记录已完成项，重跑会跳过；窗口里可勾选「强制重新下载」。

只有单文件 MP4 直链支持字节级续传（X 视频绝大多数属于此类）；分片流 / 音视频分离流自动改用 yt-dlp 原生下载，其 `.part` 文件支持续传但不能跨会话按字节恢复。

修复记录：交付前反方复核发现，服务器忽略 Range 时 curl 报错退出但 `-w` 仍打印 `200 0`，原判定会把半成品误标为完成。已改为「续传必须收到 206 且本次传输字节数 > 0」，并完整回归 5 项全通过。

未自动化实测：窗口里点「停止」按钮这条交互（验证用的是更强苛的强杀进程，代码路径已审查）；多视频单条推文（多个直链）的实际下载。

测试产物、临时窗口均已清理；`下载\X视频` 里用户原有的 1.2 GB 视频未触碰。

## 首版范围

仅做「窗口 + 批量 + 断点续传」。通用站点下载、取直链交给 FDM、m3u8 转 mp4 仍分别使用原有的 `通用视频下载.bat`、`获取X视频直链-给FDM.bat`、`m3u8批量转换.bat`，未搬进本窗口。

## 限制

- 中国大陆环境需要能访问 X 的代理；脚本自动识别 Windows 系统代理 / 环境变量 / 常见本地端口，也可命令行 `-Proxy` 指定。
- Win10 1803+ / Win11（依赖系统自带 `curl.exe` 与 PowerShell 5.1），Win7 不支持。
- 需要登录的内容可在脚本同目录放 `cookies.txt`，或用 `-Login`（需先完全关闭 Chrome）。
- 工具不提供绕过登录、付费墙、加密或版权保护措施的能力，请只下载有权保存的内容。
