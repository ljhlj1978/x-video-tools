# 窗口版「不再弹出 PowerShell 窗口」改造 · 交付说明

日期：2026-11-24

## 结论

可以，已经改好了。以前 `.bat` 直接拉起 `powershell.exe`，所以窗口旁边会跟着一个黑色控制台窗口。现在窗口版改用 **Windows 自带的图形脚本宿主（`.vbs`）** 启动，它本身没有控制台窗口，启动 PowerShell 时也不为其创建控制台窗口：

- **推荐双击 `X视频批量下载.vbs` / `m3u8批量转换.vbs`** → 桌面只出现程序自己的窗口，完全没有任何黑框。
- 原来的两个 `.bat` 保留为兼容入口，内容简化成「把参数转交给 .vbs」：cmd 窗口一闪即退，不会再有常驻的 PowerShell 黑框。
- 四个命令行工具（`下载X视频.bat`、`获取X视频直链-给FDM.bat`、`通用视频下载.bat`、`m3u8转mp4.bat`）本来就靠黑框显示进度和暂停，保持原样。

两个 `.ps1` 主程序 **一行未改**，托盘常驻、断点续传、批量下载 / 转换逻辑全部照旧。

## 改动的文件

| 文件 | 改动 |
| --- | --- |
| `X视频批量下载.vbs`（新） | 无控制台启动器，纯文本、系统自带宿主、无需安装/编译/管理员权限 |
| `m3u8批量转换.vbs`（新） | 同一个启动器的副本，靠文件名含 `m3u8` 选择 `m3u8_gui.ps1` |
| `X视频批量下载.bat`、`m3u8批量转换.bat` | 改为只做 VBS 转发（保留 `%*` 参数，拖放可用）；按中文系统 ANSI(GBK) 保存，避免中文文件名被 cmd 读成乱码 |
| `使用说明.txt` | v6 → v7：新增第十二节「无黑框启动」，第一节补推荐入口，第十一节补入口说明 |

启动器逻辑：以 `WScript.Shell.Run(cmd, 0, False)` 隐藏窗口且不等待，命令行里的每个参数都做引号包裹（尾部反斜杠加倍、内部引号转义）。因为不经过 `cmd.exe`，链接里的 `&`、`?`、`[ ]` 不会被误当命令分隔符。

**过程中的一个真实插曲**：第一版 bat 里保留了 `powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden` 作为兜底分支，本机安全软件（HipsTray）把刚写入的两个 bat 移除了，导致一次启动失败。已去掉该兜底、简化为纯 VBS 转发，复测两个入口均正常且文件不再被动过。说明文档里也写了「以 .vbs 为准、必要时加白名单」。

**未自动化实测（如实标注）**：
1. 把链接 / 文件**真实拖到 .vbs 图标上**的资源管理器拖放动作（参数拼装逻辑已用等价参数数组验证）。
2. 非中文系统（ACP ≠ 936）下 bat 里的中文文件名；该场景直接双击 .vbs 不受影响。
3. 默认终端被设为 Windows Terminal 的机器上是否另有窗口（本机快照未见任何终端宿主窗口）。
