# 窗口版「点 × 收进系统托盘」改造 · 交付说明

日期：2026-11-24

## 结论

可以，已经做好了。`X视频批量下载.bat` 和 `m3u8批量转换.bat` 两个窗口程序现在都是：

- 点右上角 **×** → 窗口隐藏、程序**不退出**，图标留在系统托盘，正在跑的下载 / 转换在后台继续；
- **双击托盘图标**（或右键 →「显示主窗口」）→ 恢复窗口看进度、继续加任务；
- 托盘右键 →「退出程序」，或窗口右下角 **「退出程序」** 按钮 → 真正结束；
- 任务进行中请求退出会先确认，并等当前任务收尾后才关闭，不会把 curl / ffmpeg 子进程丢成孤儿。

窗口里原来的「关闭」按钮改名为「退出程序」，语义不变（仍是彻底退出），避免和点 × 混淆。任务栏「最小化」按钮仍是普通最小化，不进托盘。命令行黑框版行为不变。

## 使用提醒

- Windows 11 常把托盘图标折叠进任务栏的「^」：点开「^」，把图标拖到常显区；看不到气泡通知时检查「设置 → 系统 → 通知」。
- **关掉的是窗口，不是任务**。想停下载请用窗口里的「停止（可续传）」，或直接退出程序；两者都保留半成品，下次可续传。
- 后台任务完成时不再弹模态对话框（改为托盘气泡），避免无人值守时卡住。
